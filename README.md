# 호스피탈. 6인의 의사 Wii 한글패치

Wii 일본판 **호스피탈. 6인의 의사(Hospital. 6-nin no Ishi, SPTJEB)**용 비공식 한국어 패치입니다. 다음 항목을 한국어로 바꿨습니다.

- **대사·안내 메시지 전체:** 서로 다른 문장 23,083개, 화면 기준 52,799쪽
- **실행파일 문자열 2,691개:** 메뉴, 확인 창, 진찰·검사 항목, 결과 화면 등
- **에피소드 제목 71개**와 **도움말(HELP) 그림 133장**
- **화면 그림 글자:** 타이틀, 스트랩 주의 화면, 수술 시작, 검시 PC, 진단 메뉴, 결과 화면, 엔딩 로고 등
- **게임 글꼴:** 한글 2,350자 전체를 나눔스퀘어네오로 새로 그렸습니다

현재 배포판은 **v1.0 (2026-11-13)**입니다.

## 게임 소개 및 대상 버전

『호스피탈. 6인의 의사』는 아틀라스가 2010년 Wii로 발매한 의료 어드벤처 게임입니다(북미판 『Trauma Team』). 『카두케우스』 시리즈의 한 작품입니다. 종합병원 리잘감 제일병원에 모인 여섯 의사의 이야기를 각자의 에피소드로 따라갑니다. 외과 수술, 응급 구명, 정형외과, 내시경, 진단, 법의학 검시를 Wii 리모컨과 눈차크로 직접 해 봅니다.

이 패치는 **일본판 SPTJEB (Rev 0)**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 맞는지가 중요합니다.

## 패치 적용 방법

### 1. RVZ·WBFS·WIA를 ISO로 바꾸기

xdelta는 **압축하지 않은 ISO**에만 적용됩니다. 원본이 RVZ 등 압축 형식이면 먼저 Dolphin에서 ISO로 바꿉니다.

1. Dolphin 게임 목록에서 게임을 우클릭하고 **파일 변환**을 고릅니다.
2. 형식을 **ISO**로 정하고 변환합니다. 이때 "쓰레기 데이터 제거"는 끄세요. 켜면 해시가 달라집니다.

명령줄에서는 다음과 같이 합니다.

```powershell
.\DolphinTool.exe convert -i '.\Hospital. 6-nin no Ishi (Japan).rvz' -o '.\Hospital. 6-nin no Ishi (Japan).iso' -f iso
```

### 2. 해시 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Hospital. 6-nin no Ishi (Japan).iso'
```

위 표와 다르면 적용을 중단하세요.

### 3. xdelta UI로 적용

1. 릴리즈에서 `Hospital_6nin_no_Ishi_Wii_KO_v1.0.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Hospital. 6-nin no Ishi (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄로 적용

```powershell
.\xdelta3.exe -d -s '.\Hospital. 6-nin no Ishi (Japan).iso' '.\Hospital_6nin_no_Ishi_Wii_KO_v1.0.xdelta' '.\Hospital. 6-nin no Ishi (Korean).iso'
```

결과 ISO는 Dolphin에서 그대로 실행하거나, 원하면 다시 RVZ로 변환해 보관해도 됩니다.

**세이브**
- 게임 ID는 원본과 같으므로 Wii 세이브 데이터는 원본판과 함께 쓸 수 있습니다.
- 원본판에서 만든 세이브 스테이트는 쓰지 마세요.

## 한글화 범위

- **대사·메시지:** 여섯 의사의 에피소드 전체, 수술·진단·검시 중 안내, 튜토리얼, 메달 챌린지, 엔딩. 서로 다른 문장 23,083개를 모두 번역했습니다.
- **실행파일 문자열 2,691개:** 메뉴·옵션, 에피소드 선택, 진찰·문진·검사 항목, 증상 목록, 결과·평가 화면, 확인 창.
- **그림 글자:**
  - 에피소드 제목 71개, 도움말(HELP) 그림 133장
  - 타이틀 메뉴, 스트랩·눈차크 주의 화면, 난이도 설명, 수술 시작 문구
  - 검시 PC(규명·증거 완성), 진단 메뉴, 분석·혈액 검사, 영상 진단, 두개골 퍼즐 등 화면 표제 20종
  - 엔딩 로고 "6인의 의사"
- **글꼴:**
  - 게임 글꼴(대사·메뉴)은 한글 2,350자 전체를 나눔스퀘어네오로 그렸습니다.
  - 그림 글자는 나눔스퀘어네오와 서울한강체, 아주 작은 글씨는 갈무리를 썼습니다.
- **원문 유지:** 음성(일본어), 저작권 표기, 게임에서 쓰이지 않는 이전 작품의 남은 그림.

## 알려진 한계

**표기**
- 일본어 후리가나(루비)는 한국어에 맞지 않아 지웠습니다.
- 실행파일 문자열은 원래 칸 크기에 맞추느라 일부를 줄여 적었습니다.
- 대사 일부는 한 줄이 원문보다 길어 화면 가장자리에 가깝게 붙을 수 있습니다.

**확인 범위**
- Dolphin에서 직접 플레이하며 다음을 확인했습니다.
  - 타이틀, 프롤로그, 에피소드 선택, 옵션
  - 나오미(검시) 1~2화, 행크(정형외과) 2화, 토모에(내시경) 2화, 게이브(진단) 2화
  - 각 화면의 도움말 그림, 결과 화면, 엔딩 로고
- 마리아(응급 구명)와 CR-S01(외과) 에피소드, 후반부 대사는 데이터가 한국어로 바뀐 것만 확인했습니다.
- 실기 Wii에서의 동작은 확인하지 못했습니다. 결과 ISO는 가짜 서명이므로 실기에서는 USB 로더 등 서명 검사를 하지 않는 환경이 필요합니다.

문제가 있으면 이슈로 알려 주세요.
